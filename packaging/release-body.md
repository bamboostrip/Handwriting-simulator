## 产物下载

> 点击链接直接下载本版本对应文件，无需翻找页面底部 Assets。

- Windows 便携完整包 ([HandWriteSim-windows-x86_64.zip](https://github.com/bamboostrip/Handwriting-simulator/releases/download/{TAG}/HandWriteSim-windows-x86_64.zip))：首次使用，解压即用（内含 `HandWriteSim.exe`）
- Windows 单文件升级包 ([HandWriteSim-windows-x86_64.exe](https://github.com/bamboostrip/Handwriting-simulator/releases/download/{TAG}/HandWriteSim-windows-x86_64.exe))：老用户下载后直接替换旧的 `HandWriteSim.exe` 即可，应用内自动更新也是用这个文件
- Linux 便携完整包 ([HandWriteSim-linux-x86_64.zip](https://github.com/bamboostrip/Handwriting-simulator/releases/download/{TAG}/HandWriteSim-linux-x86_64.zip))；单文件升级 [HandWriteSim-linux-x86_64](https://github.com/bamboostrip/Handwriting-simulator/releases/download/{TAG}/HandWriteSim-linux-x86_64)，替换旧二进制后 `chmod +x`
- macOS 便携完整包 ([HandWriteSim-macos-arm64.zip](https://github.com/bamboostrip/Handwriting-simulator/releases/download/{TAG}/HandWriteSim-macos-arm64.zip))：Apple Silicon；单文件升级 [HandWriteSim-macos-arm64](https://github.com/bamboostrip/Handwriting-simulator/releases/download/{TAG}/HandWriteSim-macos-arm64)，直接替换旧二进制

## 说明

- 便携包解压即用（可执行文件 + `presets/` 预设 + `backgrounds/` 背景 + `fonts/` 字体目录），整个文件夹可随意移动 / U 盘拷贝。
- 首次运行会自动创建缺失的 `fonts/`、`backgrounds/`、`presets/` 目录。
- 字体请自备：商业字体版权原因发布包不含字体，下载后放入 `fonts/` 即可，推荐免费可商用的霞鹜文楷（LXGW WenKai）。
- 预设中的字体路径（如 `fonts/云烟体.ttf`）为占位名称，放入对应字体文件后即可直接使用，也可以改用其他字体。
