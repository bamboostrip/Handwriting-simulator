# 「关于」内使用指南对话框 + 高亮功能文档补全 设计规范

## 1. 背景与目标

近期上线的高亮导入功能（docx 高亮→手写/打印智能混排、PDF/Word 底图高亮→自动提取填空框，
见 `2026-09-03-import-highlight-dialog-choice-design.md`）尚未写入 README，用户无从得知用法。
同时软件功能已相当多（基础排版、错字模拟、框选区域、文档底图、笔迹角色……），
需要在 GUI 内提供一份简短生动的使用介绍。

现状核查结论：

- README「功能特性」**未提及**高亮导入的两个选择对话框，也**未提及**「笔迹角色管理」与
  正文「划选标记」工具，需要补全。
- `AboutDialog`（`src/handwritesim/gui/about_dialog.py`）目前只有版本/仓库链接/更新检查，
  **没有任何使用介绍功能**，需新建。

## 2. 方案选型

指南呈现方式考虑过三种：

| 方案 | 说明 | 取舍 |
| --- | --- | --- |
| A. QMessageBox 长文本 | 最省事 | 文本过长不可读，放弃 |
| B. 单 QTextBrowser 滚动长文 | 简单 | 一眼看不到结构，章节间跳跃困难 |
| **C. 左侧章节列表 + 右侧富文本页（选定）** | QListWidget 导航 + QTextBrowser 分页 HTML | 结构清晰、可按需查阅、实现依然轻量 |

入口：按需求「在关于里面添加，点击打开一个 dialog」——在 `AboutDialog` 底部按钮行左侧加
「📖 使用指南」按钮打开 `GuideDialog`。不改动主界面布局。

## 3. GuideDialog 设计

新文件 `src/handwritesim/gui/guide_dialog.py`：

- `GuideDialog(QDialog)`，标题「使用指南」，默认尺寸约 760×540。
- 布局：左侧 `QListWidget`（定宽约 168，章节项带 emoji 图标）；右侧 `QTextBrowser`（HTML 分页）。
  `currentRowChanged` 切换右侧内容；打开时定位第一章。
- HTML 内容为模块级常量列表 `_SECTIONS: list[tuple[str, str]]`（标题, HTML），
  便于测试断言与后续增改。
- 文案要求：简短、生动（emoji、短句、要点列表），且**必须与实际 GUI 控件一致**
  （对齐按钮、错字率滑杆 0~30%、重写方式/涂改方式选项、标记按钮文案等均已核对）。
- 主题：QTextBrowser 已被浅/深两套 QSS 覆盖，正文颜色继承主题；高亮色块示意用
  `<span style="background:#fff3a3;color:#333">`（黄）/ `#d6f5d6`（绿）自带底色，
  深浅主题下均可读。
- 章节（6 页）：
  1. 🚀 快速上手 —— 三步：输入文字→选字体/背景→导出；自动预览说明
  2. ✏️ 基础排版 —— 对齐/缩进、字距/行距/字号与 σ、笔画扰动、边距、颜色、预设、多页预览、导出 PNG/PDF
  3. 📥 进阶 · 导入 docx 智能混排 —— 高亮→手写、未高亮→打印体；导入弹窗三选一含义；
     划选标记按钮；笔迹角色管理
  4. 📄 进阶 · 文档底图与手写填空 —— PDF/Word 底图导入；高亮色块自动识别填空框
     （提取填空框/保留完整底图）；框选文字区域与逐区域参数
  5. 🧩 进阶 · 错字模拟 —— 错字率滑杆、重写方式、涂改方式
  6. 💡 小技巧与常见问题 —— 纯背景预览、边界提示、预览底色、便携目录、字体版权提示
