## 一、结论：两项功能都可移植

| 功能 | 可移植性 | 说明 |
|---|---|---|
| 表格识别导入 | **完全可移植** | 核心是「docx 结构解析 + PDF 字符流匹配 + 像素擦除」，与语言无关；Python 已有 `python-docx`、`pypdfium2`、`numpy`、`PIL`，`classify_highlight_color` / `strip_tag_syntax` / `ExtractedChar` / `pdf_to_images_with_regions` 等基础设施齐备 |
| 右栏重排 | **可移植（适配 Qt 控件模型）** | Rust 用 Naive UI `NCollapse`，Python 用自绘 `QPushButton[collapsible=true]` + 内容容器（`region_dialog.py` 已有同款折叠模式可复用）；6 组分组、统一导入入口、折叠状态持久化、主题移入状态栏均可实现 |

差异点（有意为之）：
- Rust 前端是 Vue 响应式；Python 是 Qt 命令式。折叠组用 `CollapsibleSection` 封装，状态写 `QSettings`。
- Rust 主题三态 `auto/light/dark` 存 localStorage；Python 存 `QSettings`，新增 `ThemePreference` 与 `effective_dark()`。
- Python 没有底部状态栏，本次新增 `QMainWindow.statusBar()`（左侧版本+关于与更新，右侧主题切换）。

## 三、接口契约

### 3.1 `core/docx_io.py` 新增（core-tables 负责）

```python
class CellVMerge(Enum):
    NONE = "none"
    RESTART = "restart"
    CONTINUE = "continue"

@dataclass
class CellRun:
    text: str
    highlight: str | None = None          # w:highlight @w:val 小写名（不含 shd 回退）
    color: tuple[int, int, int] | None = None   # w:color → RGB
    sz_half_pt: int | None = None         # w:sz（半磅）

@dataclass
class ParsedCell:
    runs: list[CellRun] = field(default_factory=list)
    jc: str | None = None                 # 首段 w:jc 直接格式
    run_sz_half_pt: int | None = None     # 首段首个 run 的 w:sz
    grid_span: int = 1
    v_merge: CellVMerge = CellVMerge.NONE
    col_start: int = 0

@dataclass
class ParsedRow:
    cells: list[ParsedCell] = field(default_factory=list)

@dataclass
class ParsedTable:
    grid_cols: int = 0
    rows: list[ParsedRow] = field(default_factory=list)

@dataclass
class BodyParagraph:
    text: str                             # 拼接后的可见文本（匹配消费用）

BodyElement = BodyParagraph | ParsedTable

def is_gray_highlight(val: str) -> bool: ...
def load_body_stream(path: str | Path) -> list[BodyElement]: ...
```

要点（对齐 Rust `docx_io.rs::parse_body_stream`，见其 diff）：
- 文档顺序遍历 `document.element.body` 的子元素：`w:p` → `BodyParagraph`，`w:tbl` → `ParsedTable`。
- 表格：`tblGrid/gridCol` 计数（自闭合元素也要计）；行 `w:tr`；单元格 `w:tc`。
- `gridSpan`（`tcPr/gridSpan@w:val`）默认 1；`vMerge`（`val=restart` → RESTART，无 val → CONTINUE）。
- `col_start` 由行内前序单元格 `grid_span` 累计。
- vMerge 续行格未显式声明 gridSpan 时，从上方同列覆盖格继承跨列数。
- 单元格内多段落：runs 之间插入 `CellRun(text="\n")` 分隔。
- 嵌套表格（`tbl` 深度 ≥2）内容整段忽略（内层文本不得泄入外层格）；`w:txbxContent` 内容忽略。
- `jc` 取单元格首段的 `w:pPr/w:jc@w:val`；`run_sz_half_pt` 取首段首个 run 的 `w:rPr/w:sz@w:val`。
- 异常兜底：解析失败抛 `ValueError`（调用方 `doc_render` 会 try/except 退化为无表格）。

### 3.2 `core/docx_tables.py`（core-tables 负责，新文件）

```python
@dataclass
class TableCellView:
    text: str                     # strip_tag_syntax 后的可见文本
    col_start: int
    col_span: int
    v_merge: CellVMerge
    align: int                    # 0 左 / 1 中 / 2 右
    sz_half_pt: int | None
    printed: bool                 # 原文含 {{打印 / 【打印
    skip_printed: bool            # 灰色高亮 → 整格保留印刷底图
    highlight: str | None         # 首个非灰 w:highlight；无则首个具饱和度 w:color 经 classify_highlight_color 映射

@dataclass
class TableRowView:  cells: list[TableCellView]
@dataclass
class TableView:     index: int; rows: list[TableRowView]

def build_table_views(stream: Sequence[BodyElement]) -> list[TableView]: ...

@dataclass
class CellMatch: char_idxs: list[int]
@dataclass
class TablePageMatch:
    table_index: int
    row_matches: list[list[CellMatch | None]]
    located_cell_count: int
    locatable_cell_count: int
    located_on_page: bool

def locate_tables_on_page(stream, views, chars: list[ExtractedChar], start_element: int) -> tuple[list[TablePageMatch], int]: ...

@dataclass(frozen=True)
class RectPx: x: int; y: int; w: int; h: int

def infer_cell_rects(view: TableView, m: TablePageMatch, chars: list[ExtractedChar]) -> list[RectPx | None]: ...
```

常量与规则（逐条对齐 `docx_tables.rs`，注释里保留原因，便于后续维护）：
- `PARAGRAPH_WINDOW=500`、`CELL_WINDOW=3000`、`CELL_MATCH_RATIO=0.6`、`TABLE_LOCATED_MIN_CELLS=2`、
  `TABLE_CONSUMED_RATIO=0.5`（消费判定用**严格大于**）、`PARAGRAPH_MATCH_RATIO=0.6`、`COLOR_FILL_MIN_SPREAD=30`。
- 归一化 = 去空白与控制字符后逐字符（docx 与 PDF 字符流同口径）。
- 两指针子序列匹配：失败回滚 cursor（`consume_on_fail=False`），成功/部分命中后 cursor 推进到最后命中字符之后。
- 单元格文本归一化长度 < 2 不参与匹配（防跨页单字误匹配），直接回退带推断。
- 每页只从 `start_element` 起走；段落匹配失败不推进 `matched_upto`；表格定位比例 > 0.5 才消费；
  分割中的表钳制 `matched_upto` 不得越过自身。
- `infer_cell_rects`：命中格 = 字符 bbox 外扩 2px；未命中格 = 行带 × 列带交集内缩 3px；续行格 None。

### 3.4 `core/doc_render.py`（render-pipeline 负责）

```python
@dataclass
class TablePageResult:
    regions: list[TextRegion] = field(default_factory=list)
    cell_rects: list[RectPx] = field(default_factory=list)
    outer_rects: list[RectPx] = field(default_factory=list)
    next_start_element: int = 0

def merge_wrap_line_boxes(boxes: list[BoundingBox], chars: list[ExtractedChar]) -> list[BoundingBox]: ...
def erase_char_boxes(arr: np.ndarray, chars: list[ExtractedChar], idxs: Sequence[int], pad: int = 2) -> None: ...
def process_tables_on_page(
    stream, views, chars, start_element: int, page_num: int, dpi: int,
    arr: np.ndarray, color_map: dict[str, int], next_role_id: list[int],
) -> TablePageResult: ...
def pdf_to_images_with_regions(pdf_path, out_dir, dpi=200, prefix=None, body_stream=None) -> tuple[list[Path], list[TextRegion]]: ...
```

管线顺序（严格对齐 Rust，注释保留原因）：
0. 表格：定位 → 命中格逐字符擦白（保表格线）→ 生成单元格 `TextRegion`（`table_index` 1 基）
1. 标签：`extract_pdf_page_tags(..., exclude_rects=table_result.cell_rects)`——
   与单元格矩形**相交**的标签仍然擦除标签框，但**不生成独立区域**（避免与单元格区域重复）
2. 高亮框：`detect_highlight_boxes` 后先按表格外包围矩形 `outer_rects` 分流：
   表内框不整框擦白（保表格线）、不生成区域；表外框再 `merge_wrap_line_boxes`（换行签名合并）后擦白
3. 表外高亮框 → `combine_page_regions_with_role_map`；`all_regions.extend(table_regions)` 前排（或按 y 排序，见下）
4. `document_to_page_images_with_regions` 对 `.docx` 先 `load_body_stream`（失败退化为空流，不阻塞导入）再转 PDF

单元格区域字段：`x/y/w/h`（命中 bbox 外扩水平 6 / 竖直 4；推断矩形不扩）、`text`、`role_id`（高亮色走共享
`color_map`，首次出现 next_role_id 递增）、`highlight`、`printed`、`page`、`font_size`（命中字符经
`_resolve_font_size_px` 校准，无则 `sz_half_pt/2*scale` 四舍五入）、`align`、`margin_left/right=4.0`、
`margin_top/bottom=2.0`、`table_index`。

另修（同属 0.5.0）：`_word_com_script` 收尾 `try { $word.Quit() } catch { }` + `if (Test-Path <pdf>) { exit 0 } else { exit 1 }`。

  手写体与原打印体都可选字体文件（移除 `printed` 限制与相应校验限制）。
