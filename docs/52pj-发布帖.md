# ★ 本次更新回帖（2026-08-25，直接复制跟帖用，不发进主楼）

各位吾友，软件又更新了一波 o/ 这版的重点是**框选录入**，可以说把「手写填充」这个玩法补齐了：

**1. 框选录入文字（本版重点）**

以前文字只能按边距从上往下整页排，现在直接在预览图上**拖框**，想让字出现在哪，就在哪画个框：

- 框里可以手写体，也可以切「打印体」规规矩矩填表，**手写 / 打印混排**没压力；
- 每个框都能单独设字体、字号、颜色、对齐、缩进、边距，连**错字率和涂改样式都能每个框单独调**（不设就跟随全局）；
- 框完不满意？直接**拖动、拉八个方向的把手缩放**二次微调，还能指定这个框写在第几页；
- 框里的文字独立排版，写超了自动截断在框内，不会把后面页面弄乱；
- 区域编辑器里还有个小型的富文本段落编辑器，逐段设对齐 / 缩进，支持直接导入 docx 段落。

**2. 自由选择 PDF 背景（文档底图）**

现在**任意 PDF / Word 文档都能导入当背景**，程序会把每一页渲染成底图，直接在「打印稿」上框选手写填写：

- 试卷、申请表、实验报告模板、单位表格……统统安排上；
- 想在表格某一栏手写？框住那栏就行；
- 不输入正文也能先预览纯背景，方便先摆好版式再逐页框选。

**3. Rust 版 GUI 重构：Slint → Tauri 2**

Rust 版为了把框选、文档底图这些吃交互的功能做好，GUI 方案从原来的 Slint 换成了 **Tauri 2（系统 WebView 渲染）**：

- 框选拖拽、缩放、悬浮高亮这类复杂画布交互，在 WebView 里实现顺手得多，功能两个版本同步上线；
- 顺手解决了之前 Slint 中文输入法候选框定位的毛病；
- 界面整体焕新（Vue 3），观感现代了不少；
- 还摆脱了 Slint 的 GPL 许可限制，Rust 版现在也是 **MIT 开源**。

下载地址不变（原楼里的 GitHub Releases），两个版本都更新了，欢迎体验，有 bug 回帖或 GitHub 提 Issue 都行 o/

## 【起因】为啥做这么个软件

单位隔三差五就要交**手写思想汇报**，一动笔就是好几页，抄到后面手腕子直接抗议，写过的兄弟都懂。

我就寻思，这年头顶顶的，能不能让电脑替我写？

于是去网上找了一圈同类项目（最出名的应该是 handright），用是能用，但总觉得差点意思：

- **大部分只有命令行**，改个参数还得改代码，对不写代码的同事来说门槛太高；
- **不能直接导入 docx**，汇报明明是在 Word 里打好的，还得手动复制粘贴，格式全丢；
- **不能调对齐方式**，标题要居中、正文要首行缩进、落款要靠右，它统统做不到，排出来一眼假；
- **渲染太慢**，逐像素的 Python 循环，一份报告等好几分钟，想调个参数预览一下更是折磨。

干脆，自己造一个。

折腾了一段时间，就有了这个 **手写模拟器（HandWriteSim）**。今天发出来分享给坛友们，**项目已开源**，源码随便看。

## 【软件介绍】它能干啥

一句话：**你给它文字，它还你一沓"手写"图片**。

把文本（或 docx）丢进去，选一款手写字体、一张信纸背景，程序会按真实书写习惯排版，并对**字距、行距、字号、笔画位置、笔画角度**施加随机扰动——每个字、每一页都独一无二，不会有"复印感"。还支持**模拟写错字涂改**（右上方小字重写或后文正常位置重写，支持线划、双线、斜杠、打叉多种涂改方式），以及**一键导出 PDF**，整份"手写"文档直接打印上交。

这版新增**框选录入**：在预览图上拖个框，字就写在哪；再配上**任意 PDF / Word 文档底图**，试卷、申请表、实验报告也能直接"手写填写"。

## 【功能一览】

- **框选录入文字（新）**：在预览图上拖个框，文字就只在框里排版渲染；支持手写体 / 打印体混排，每个框可单独设字体、字号、颜色、对齐缩进、错字率，框还能拖动、缩放二次微调，也可以指定写在第几页；
- **PDF / Word 文档当背景（新）**：任意 PDF 或 Word 文档导入即成多页底图（试卷、申请表、报告模板都行），直接在「打印稿」上框选手写填写；
- **纯背景预览（新）**：没输入正文也能先出预览，方便先摆好版式再逐页框选；
- **docx 直接导入**：Word 里的左对齐 / 居中 / 右对齐 / 首行缩进自动解析还原，导入即排版，不用重调；
- **富文本段落排版**：界面上点一下就能给段落设置左对齐、居中、右对齐、首行缩进，标题居中、落款靠右都不在话下；
- **以假乱真的扰动**：字水平间距、行距、字号、笔画位移、笔画旋转，每项都能单独调扰动强度，想工整一点或潦草一点随你；
- **写错字功能**：模拟真实书写时的涂改痕迹——错字率可调、支持右上方小字重写或后文正常位置重写，涂改方式有线划、双线、斜杠、打叉四种，写出来的东西更有人味儿；
- **PDF 导出**：支持直接导出为 PDF（300 DPI，每页 PNG 无损嵌入），一键生成整份"手写"文档，方便打印上交；
- **实时预览**：停止输入 0.3 秒自动出预览，多页自动分页、可翻页查看，所见即所得；
- **快**：渲染引擎用 numpy + scipy 向量化重写，预览一页约 0.15 秒，比老式逐像素循环快几十倍，调参数不用干等；
- **预设系统**：调好一套参数存成预设，下次下拉框一键切换，"红纸版""信纸版"秒换；
- **图形界面 + 命令行双模式**：同事用 GUI 点点鼠标，程序员用 CLI 批量生成；
- **便携免安装**：打包成单个 exe（约 49MB），下载解压双击就用，整个文件夹拷到 U 盘里都能跑；
- **跨平台**：Windows / macOS / Linux 都支持。

## 【Rust 版也已开源】

除了 Python 版，我还用 **Rust** 重写了一个版本（[Handwriting-sim-rs](https://github.com/bamboostrip/Handwriting-sim-rs)），核心逻辑与 Python 版对齐，功能上也会持续同步更新。

Rust 版的特点：

- **性能更好**：编译型语言零运行时开销，大批量导出时速度优势更明显；
- **界面已换 Tauri 2（新）**：为了实现框选录入、PDF 文档底图这些吃交互的功能，GUI 从原来的 Slint 框架迁移到了 **Tauri 2 + 系统 WebView**，界面焕新（Vue 3），之前 Slint 中文输入法候选框定位不准的毛病也一并解决了；
- **单文件更小**：打包后约 20MB，比 Python 版更轻量；
- **开源协议更干净**：迁移 Tauri 2 后摆脱了 Slint 的 GPL 传染，Rust 版全项目 **MIT 开源**；
- **支持老版本 Windows 10**：对还在用 Win10 老版本的机器也能跑起来，依赖的系统 WebView2 组件 Win10 / Win11 一般都自带（原本想冲 Win7，但现代 UI 框架和依赖库基本都不支持 Win7 了，日常维护老版本的成本也确实扛不住）。

两个版本的功能会持续对齐，选哪个看个人偏好就行。

## 【使用方法】30 秒上手

1. 到 Release 下载对应系统的压缩包，解压；
2. 往 `fonts/` 文件夹里丢一个手写字体（**因版权原因不随包附字体**，推荐开源免费的「霞鹜文楷」，手写观感很好，README 里还有几个备选）；
3. `backgrounds/` 里内置了十几种信纸、格子纸、红纸背景，也可以用自己的图，或者在「文档底图」处直接**导入 PDF / Word 文档**把整份文档当背景（试卷、表格、报告模板都行）；
4. 常规用法：粘贴文本或「导入 docx」，点**导出**，完事；
5. 框选玩法：点**「框选文字」**在预览图上拖框，框里输入的文字独立排版渲染——填表、答卷指哪写哪，配合 PDF 底图食用更佳。

首次运行会自动在 exe 旁边创建 `fonts/`、`backgrounds/`、`presets/` 三个文件夹，资源往里放就行，整个文件夹搬去哪都能用。
